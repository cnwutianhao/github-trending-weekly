## 一、本周先说结论

本周榜单的关键词不是“又一个模型”，而是 **Agent 工程化**：代码审查、并行 Agent、上下文压缩、知识库、互联网访问、工程 Skills、文档转 Markdown，以及 HTML 到视频的内容流水线同时升温。与此同时，Home Assistant 和 Cilium 这样的成熟基础设施仍然在榜，说明开发者对本地控制、网络安全和可观测性的需求并没有被 AI 热潮掩盖。

把这些项目放在一起看，可以得到一条主线：

> **Agent 正在从“能执行任务”进入“能被编排、被约束、被压缩、被审查，并接入真实世界数据”的阶段。**

### 本周最明显的 5 个方向

#### 1. AI Coding 开始补齐质量与治理层

Open Code Review、Claude Code、Cline 和 agent-skills 都不只是生成代码，而是围绕代码库理解、规则执行、审查、工具调用和工程流程展开。AI Coding 的重点正在从“写得快”移动到“改得对、看得懂、能合并”。

#### 2. 多 Agent 协作需要专门的编排与隔离环境

Orca、Worktrunk 和 Sponsor 页面对应的 Agent harness 项目，都在解决并行任务、独立工作区、上下文隔离和任务协调问题。多个 Agent 同时工作之后，真正困难的不是启动它们，而是避免互相覆盖、重复劳动和失去状态。

#### 3. 上下文工程成为独立的性能问题

affaan-m 的 Agent harness 优化项目、mksglu 的上下文窗口优化项目，以及 WeKnora、Agent-Reach 共同说明：Agent 的瓶颈越来越常见于上下文过长、工具输出噪声、知识检索不稳定和外部信息接入成本过高。

#### 4. Agent 正在获得“眼睛”和“手脚”

Agent-Reach 负责访问互联网，God's Eye View 将实时空间数据带到浏览器，Hyperframes 负责把 HTML 渲染成视频，Home Assistant 则把软件连接到现实设备。Agent 的执行范围正在从代码库扩展到网页、媒体、地理空间和家庭自动化。

#### 5. 内容质量与人类表达成为新的工具赛道

humanizer、no-ai-slop 和 i-have-adhd 都在约束 AI 输出风格；MarkItDown 负责把文档转换为 Markdown；知识工作插件则把专业工作流打包给用户。这里的竞争点不只是生成，而是让生成结果更自然、更可读、更能进入后续工作流。

# 三、21 个热门项目逐个看

## 1. [alibaba/open-code-review](https://github.com/alibaba/open-code-review)

**语言：** Go  
**本周增长：** +15.0k Stars  
**定位：** 面向真实工程的混合架构代码审查工具

### 它是什么

Open Code Review 是一个面向代码质量和安全检查的工程化审查工具，强调在大规模工程环境中进行快速、稳定和可落地的审查。

### 它能做什么

它可以接入代码变更流程，对提交、差异和项目规则进行自动检查，并把问题反馈给开发者或审查流程。

### 核心亮点

- 将规则检查与更灵活的分析能力组合起来。
- 面向大规模代码库和团队协作场景。
- 关注审查速度、准确度和工程可接入性。

### 谁适合用

企业研发团队、平台工程团队、代码安全团队和需要统一质量门禁的开源项目。

### 为什么值得关注

**S 级关注** AI 生成代码越多，自动化审查和质量治理越重要。需要重点验证误报率、规则扩展方式和 CI/CD 集成成本。

> **代码生成扩大了产量，代码审查决定了这些产量能否安全进入生产。**

- 体现 AI / Web 应用从文本走向现实世界数据。

## 4. [ayghri/i-have-adhd](https://github.com/ayghri/i-have-adhd)

**语言：** Python  
**本周增长：** +5.6k Stars  
**定位：** 让 Coding Agent 输出更直接、更容易执行的 Skill

- 把个人偏好变成可复用的输出协议。
- 适用于多个 Agent 客户端和开发任务。

### 谁适合用

希望 Agent 更简洁的开发者、团队内部 AI 协作用户和 Skill 设计者。

### 为什么值得关注

**A+ 级关注** 它说明 Agent 体验可以通过协议工程改善，而不仅是等待模型自然变聪明。

## 5. [stablyai/orca](https://github.com/stablyai/orca)

**语言：** TypeScript  
**本周增长：** +5.4k Stars  
**定位：** 面向并行 Agent 团队的 Agent Development Environment

### 它是什么

Orca 是一个用于管理一组并行 Coding Agent 的开发环境，目标是让多个 Agent 同时处理任务，并保持任务之间的边界和状态。

### 它能做什么

- 面向 Agent fleet，而不是单个会话。
- 强调并行执行和任务协调。
- 为多 Agent 工作流提供可视化或统一控制入口。

### 谁适合用

AI Coding 团队、自动化开发平台和需要同时处理多个独立任务的开发者。

### 为什么值得关注

**S 级关注** 并行 Agent 会成为生产力放大器，但前提是隔离、合并、冲突解决和权限控制足够可靠。

> **多 Agent 的难题不是让它们同时运行，而是让它们同时运行后仍然可控。**
